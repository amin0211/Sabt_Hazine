# costio-ios-voice
CostioIosVoice control for Flet

## Installation

Add dependency to `pyproject.toml` of your Flet app:

* **Git dependency**

Link to git repository:

```
dependencies = [
  "costio-ios-voice @ git+https://github.com/MyGithubAccount/costio-ios-voice",
  "flet>=0.84.0",
]
```

* **uv/pip dependency**

If the package is published on pypi.org:

```
dependencies = [
  "costio-ios-voice",
  "flet>=0.84.0",
]
```

Build your app:
```
flet build macos -v
```
